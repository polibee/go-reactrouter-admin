# 三、Resource Engine 也可以继续

你之前的：

```typescript
defineResource({
  name: "users",
  label: "resources.users.title",

  columns: [],
  fields: [],
})
```

这个设计仍然正确。

甚至我建议你坚持这个设计。

因为 Resource 本质上应该只描述：

```text
资源是什么
```

例如：

```text
User
│
├── 名称
├── 字段
├── 表格
├── 表单
├── Action
├── Permission
└── Navigation
```

而不应该描述：

```text
数据库怎么查询
```

所以：

```typescript
defineResource()
```

继续开发。

# 五、正确方式：现在先留一个 Data Source

```typescript
export interface ResourceDataProvider<T> {

  find(id: string): Promise<T>

  create(data: unknown): Promise<T>

  update(id: string, data: unknown): Promise<T>

  delete(id: string): Promise<void>
}
```

然后：

```text
现在
↓
只定义接口
```

未来再实现：

```text
ReactRouterDataProvider

RestDataProvider

GoravelProvider
```

这样不会影响你当前工作。
