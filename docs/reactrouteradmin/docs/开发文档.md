# 4. 最重要的原则：shadcn 不直接进入业务层

业务模块不推荐：

```tsx
import { Button } from "@/components/ui/button"

<Button />
```

而是：

```tsx
import { AdminButton } from "@/admin/ui"

<AdminButton>
  创建用户
</AdminButton>
```

完整层级：

```text
┌─────────────────────────────┐
│      Business Modules       │
│ User / CMS / Blog / Forum   │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│       Admin UI System       │
│                             │
│ AdminButton                 │
│ AdminTable                  │
│ AdminForm                   │
│ AdminDialog                 │
│ AdminPage                   │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│      shadcn Wrapper Layer   │
│                             │
│ Button                      │
│ Input                       │
│ Dialog                      │
│ Card                        │
└──────────────┬──────────────┘
               │
               ▼
```

# 8. shadcn 全组件封装策略

所有 shadcn 组件都应该有统一分类。

但：

> **不是项目初始化时全部安装。**

而是：

```text
Component Catalog
        │
        ▼
Component Adapter
        │
        ▼
按需安装
        │
        ▼
按需启用
```

例如：

```text

        ↓
启用 Table Package

需要 DatePicker
        ↓
启用 Calendar + Popover

需要 Command Palette
        ↓

```
