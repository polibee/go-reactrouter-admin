# 《ReactRouterAdmin v2.0 重构实施开发文档》

**项目：** ReactRouterAdmin
**当前仓库：** [polibee/reactrouteradmin](https://github.com/polibee/reactrouteradmin?utm_source=chatgpt.com)
**目标版本：** v2.0
**核心定位：** Admin Foundation
**默认语言：** English
**UI Foundation：** shadcn/ui
**Router：** React Router 7
**未来后端集成：** Goravel
**未来目标：** 类似 Laravel + Filament 的开发体验

# 0. 重构核心原则

## 0.1 本次不是重写项目

禁止：

```text
删除现有项目
↓
重新创建 React Router 项目
↓
重新复制 shadcn/ui
↓
重新开发后台
```

本次必须采用：

```text
Audit
↓
Preserve
↓
Extract
↓
Refactor
↓
Standardize
↓
Extend
```

即：

> **优先保留已经稳定的 UI 和功能，只重构架构。**


## Rule 1：禁止大规模重写

```text
DO NOT rewrite the project from scratch.
```

---

## Rule 2：每个 Phase 单独执行

```text
一个 Phase
↓
开发
↓
TypeScript Check
↓
Build
↓
验收
↓
下一个 Phase
```

---

## Rule 3：先分析再移动

任何文件移动之前：

```text
Analyze Dependencies
```

---

## Rule 4：禁止破坏现有 UI

```text
Existing UI behavior must remain unchanged.
```

---

## Rule 5：所有新文案必须 i18n

禁止：

```tsx
<Button>Delete</Button>
```

必须：

```tsx
<Button>
  {t("common.delete")}
</Button>
```

# v2.0 最终验收标准

完成后应该可以做到：

## 新增普通后台模块

只需要：

```typescript
defineResource()
```

例如：

```typescript
export const ExchangeResource =
  defineResource({

    name: "exchanges",

    label: "resources.exchanges.title",

  })
```

然后自动拥有：

```text
✓ Menu

✓ Route

✓ List

✓ Create

✓ Edit

✓ Detail

✓ Permission
```

---

直接：

```tsx
<AdminPage>

  <PageHeader />

  <TradingChart />

  <OrderBook />

  <PositionTable />

</AdminPage>
```

而会变成：

```text
ReactRouterAdmin v2

        │
        ▼

Admin Foundation

        │

 ┌──────┼─────────┐
 ▼      ▼         ▼

 CMS   Trading     AI
 │       │         │
 └───────┬─────────┘
         ▼

  Custom Business
```

然后下一阶段才开始：

```text
ReactRouterAdmin Admin Foundation
              +
        Goravel Backend
              ↓
     Goravel Admin Framework
```

最终实现你想要的体验：

```text
Goravel
+
ReactRouterAdmin
+
Resource
```

≈

```text
Laravel
+
Filament
```

但更适合你未来的：

**交易系统 + AI 平台 + CMS + 社区系统。**
